~~~
each task can be modified with a distro keyword: `fedora`, `termux` or `ubuntu`

adding the keyword adds additional actions specific for that distro (i.e.: package manager)

the same task can be "overloaded" with distro keywords
~~~


distro-agnostic task:
	task foo() {
		...
	}

distro-specific task:
	fedora task foo() {
		...
	}

multi-distro task:
	distro task foo()
		fedora {
			...
		}
all distros MUST be specified
